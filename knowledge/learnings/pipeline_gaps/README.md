# Pipeline Gaps — capability & methodology learnings

> This folder tracks **structural gaps in the Cortex agent pipeline** surfaced by live engagements —
> i.e. recurring deliverable archetypes that consultants had to build *bespoke* because no skill or
> agent covers them. Each entry is an anonymised learning plus, where drafted, a hand-off skill spec
> for the Architect tier to implement.
>
> Distinct from the other learnings folders (which capture *content* knowledge — pain points,
> benchmarks, ROI patterns). This folder captures *capability* knowledge — what the pipeline can't
> yet do.

## Rules
1. **Anonymise** — no client, stakeholder, or internal-project names. Generalise to domain + deal type.
2. **Evidence the reuse** — a gap is only worth codifying if it recurs across deals. State where else it applies.
3. **Classify** — for each bespoke archetype: was the *rendering* in-pipeline (🟡) or was it *fully* bespoke (🔴)?
4. **Hand-off, don't build** — specs here are proposals. Implementation is Architect-tier and ships under journal + telemetry + dual-checkpoint governance.
