# Banking OS Alignment Audit — 01 · Skills & Rendering Assets

**Scope:** all `.claude/commands/*.md` (incl. `deprecated/`) + Frontline rendering assets (`presentations/backbase-slides-app/README.md`, `deck-template.html`, `templates/long-form/document-template.html`).
**Standards:** `knowledge/product/banking-os.md` (substance) · `knowledge/design-system/narrative-spine.md` (voice).
**Date:** 2026-06-09.

## Headline

The **visual** brand is wired as a single source of truth (`frontline-tokens.json` — read by every Frontline skill). The **verbal/substance** brand is not: **no skill reads `narrative-spine.md` or `banking-os.md`.** This is the exact drift the spine file itself warns against ("Every narrative-producing skill and agent should read from this file… No copy-paste drift."). Result: each deliverable-producing skill can independently emit on- or off-brand positioning. Most stale framing now lives in the **canned examples** inside skill bodies (covers titled "Transforming Client Experience / digital strategy", solution maps to "Omnichannel platform / engagement platform", product enums naming "Digital Assist / Digital Engage"). Those examples are what the model imitates.

## Cascade recommendation

The single highest-leverage change is to **wire the narrative spine in the same way the visual tokens are already wired**. Today every Frontline skill opens with "Read `frontline-tokens.json` first (visual single source of truth)" — but the parallel verbal source of truth is orphaned. Add one shared, copy-paste "Read first" block to the top of every **narrative/deliverable-producing** skill — the four bespoke/Frontline builders (`executive-briefing`, `executive-briefing-slides`, `frontline-slides-html`, `frontline-slides-pptx`, `frontline-long-form`), `generate-assessment-html`, `prototype`, `usecase-doc`, and the ROI/journey orchestrators:

> **Read first (brand single source of truth):** `knowledge/design-system/frontline-tokens.json` (visual) · `knowledge/design-system/narrative-spine.md` (voice: From→To, vocabulary, retire "engagement banking / better channels") · `knowledge/product/banking-os.md` (substance: Banking OS = control plane; Nexus + Sentinel; 2 domains → 4 solutions; three value pools; resolution-loop method). Open every narrative on From→To, anchor on the AI-Native Banking OS, map opportunities to the 4 solutions, quantify with the three value pools.

This one block neutralizes most HIGH/MED findings at once (the missing-spine gap is the root cause of the stale examples), and because the spine/banking-os files are themselves the single source of truth, future brand updates propagate without re-touching each skill. Pair it with one mechanical sweep of the **canned examples** in the worst offenders (`executive-briefing-slides.md` cover, `prototype.md` token block, `usecase-doc.md` module enum, the two domain examples) so the model stops imitating retired language.
