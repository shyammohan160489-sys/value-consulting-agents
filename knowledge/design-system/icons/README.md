# Icons for the Apex engine

`lucide/` is the Lucide icon set (ISC licence, see `lucide/LICENSE`), fetched 25 Sep 2026 as `lucide-static` 1.48.0:
2,118 stroke icons on a 24 × 24 grid, stroke width 2, round caps and joins. `tags.json` maps every icon to search
words. The engine draws them as native vector shapes (`X.icon_glyph(s, "phone-incoming", x, y, size, colour)`), so
they stay crisp, recolourable and editable in PowerPoint and Google Slides, and need no image files.

The twelve PNG icons in `.claude/skills/exhibit-slides-pptx/assets/icons/` predate this set (lifted from a Claude
Design export) and stay for the stat blocks that already use them.
