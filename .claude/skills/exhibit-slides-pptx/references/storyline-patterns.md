# Storyline patterns — run BEFORE building any deck

The title chain IS the deck. Draft every deck as a title chain first, in one of these
six archetypes, and run the **flip test**: read the titles alone, in order, aloud — they
must argue the whole case with nothing missing and nothing repeated. Fix the chain, not
the slides. Voice rules (SKILL.md §5) apply to every title: one line, human, said aloud.

## Pick the archetype from the job

| Archetype | Job | Beat sequence (each beat = 1-3 slides) |
|---|---|---|
| **Ambition Walk** | Transformation / renewal proposal | moment of truth → quantified ambition → first milestone → value walk (T24) → pillars (serial detail pages) → phases + gates → governance/team → why us (short, last) |
| **Model-Bank Mirror** | Outside-in case for change | expectations moved → challengers' proof → the dare-hypothesis (falsifiable, tagged ILLUSTRATIVE until validated) → the model bank by the numbers → the technology → operating-model implications → ledgers in backup |
| **Landscape Read** | Market / strategy study | exec tracker rail (T36, re-shown per chapter) → pools → segment attractiveness (T31-class ledger) → who plays where (T32 logo maps) → whitespace → 2-3 entry options, one recommended band → first moves |
| **Selection Funnel** | Vendor / option evaluation | criteria + weights FIXED first → long-list harvey read (T31) → shortlist profiles (serial) → deep scores per criterion → decisive factors (commercials last, explicit) → recommendation + discarded named + backups warm |
| **Dossier Tour** | Learn-from-the-field | framing question → one dossier per player, SAME template ×N (kicker counts: "3 of 9") → synthesis ("what they all did") → implication for the client |
| **Workshop Arc** | Facilitation | two objectives → game rules (time-boxed exercise cards) → working exhibits the room fills → restitution → prioritize on TWO axes → decisions re-read aloud → next steps with owners |

## Title grammar (same weight as the type scale)

1. **Flip test** before any build — no exceptions.
2. **Numbers into titles when the claim is numeric** ("Monthly actives doubled, and first-time growth is slowing").
3. **Question titles at pivots only** — one per deck; a question spends tension, so place it where doubt helps.
4. **Dare-hypothesis early** in outside-in decks: a sentence the room can reject; coral-tag it until validated.
5. **Recap titles at chapter seams**, carried by the tracker rail.
6. **Serial kickers count the series** — the count is a promise of discipline.
7. **Claim in the title, consequence in the band.** Bands land once per archetype beat that decides something (ambition, hypothesis, recommendation, synthesis, decision); elsewhere use the so-what rail or nothing.

## Language discipline (unchanged, now evidence-backed)

Keep §5/§5b exactly as written — no consultant abstractions, no triads, halve everything.
Archive-scale review confirmed: the wordiest slides are the weakest. Take spine, not vocabulary.
Never import third-party benchmarks, sizings, or proprietary framework names into content.
