# Proposal Long-Form (shim)

Read `.claude/skills/proposal-longform/SKILL.md` and follow it exactly to build the
requested interactive proposal document (multilingual toggle, pricing sliders, executive
readout PDF). The working template lives in the same folder. (This shim exists only for
Claude Code versions without `.claude/skills/` support — copy it to
`.claude/commands/proposal-longform.md`.)
